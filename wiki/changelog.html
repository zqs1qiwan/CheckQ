更新日志

面向使用者的变更记录（新功能、改进、修复）。部署版本号见「设置 → 关于」与 /api/health。

0.3.17（2026-11-13）

新增

  • 任务分组 / 折叠 — 任务可设置分组；列表按组折叠，组头显示任务数、启用数、今日成功 / 失败 / 成功率、下次调度；大分组默认收起，搜索 / 筛选时自动展开；支持批量勾选后「分组…」一次归入。
  • 单次运行导出 HAR — 运行抽屉「导出 HAR」，可直接拖进浏览器 DevTools 复现；敏感值（cookie / token / 密码）自动替换为 ***。
  • 编辑器效率 — 撤销 / 重做（Ctrl+Z / Ctrl+Y）、节点复制粘贴（Ctrl+C / Ctrl+V）、按连线层级「整理」布局、MiniMap 缩略图；点击日志步骤 ↔ 画布节点双向定位。
  • 失败自动重试 — 任务级退避重试（默认最多 3 次、指数退避 5 秒起、随机抖动），跑满次数仍失败才判定任务失败；每次尝试与等待时长写进运行记录、日志与通知。

改进

  • 弹窗 / 菜单改用浏览器原生能力：焦点管理、Esc 关闭、背景 inert、顶层渲染更稳定。
  • 窄屏顶栏只保留「品牌 / 新建 / 更多 / 设置」，主题、通知、文档、身份收进「更多」；工具条分组不再把按钮挤到换行。
  • 列表表头吸顶、数字等宽对齐；设置页分区更清晰。

修复

  • 删除任务的确认弹窗在操作完成后不再卡在屏幕上；取消 / Esc / ✕ 均可关闭。
  • 提示条 5 秒后自动消失，不再需要手动点掉。
  • 通知渠道「保存」后弹窗自动关闭；「测试发送」保持在原弹窗内查看结果。
  • 部分场景下设置页打不开的问题；流程没有日志节点时运行记录不再显示为空。
