# CheckQ 迭代路线图（v0.4）

> 2026-11-13 · 目标：框架能力、交互可靠性与文档一致性持续收敛；公开内容只描述框架，不含任何实例与测试数据。

## 当前状态（v0.3.x → v0.4.4）

- 引擎：10 种节点（http/condition/set/extract/delay/random-delay/log/notify/script/foreach），单链 DAG，500 步上限；
- 存储：JSON 文件（flows/runs/templates/meta/notifications），原子写 + 变更立即 flush + SIGTERM flush；
- 调度：croner，每任务独立 cron/时区/抖动 + **任务级失败退避重试（默认 3 次，跑满才判定最终失败）**；
- 日志：默认干净模式（只出 log 节点）+ 连续日志流 + 调试模式 + 逐次尝试记录；
- 通知：12 渠道原生集成 + 站内通知中心 + 每日汇总推送；
- 模板：自动跟随（模板一改，派生任务立刻变），无手动同步；
- 交互：原生 `<dialog>` / Popover API / `color-scheme` / 容器查询，遵循 Modern Web Guidance 1.0；
- API：REST + X-API-Key + OpenAPI 3.1；MCP：stdio 工具集；
- 文档：PRD / API / MCP / 安全 / 存储 / 兼容矩阵 + 自动生成的文档站（含交互与视觉规范页）；
- 护栏：`ui-smoke` / `copy-audit` / `secret-scan` / `project-audit`，命中即 exit 1。
