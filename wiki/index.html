CheckQ 概览

CheckQ 是一个可视化 HTTP 自动化流程引擎（框架 / 平台）：把「每天要做的签到、监控、定时请求」做成可编辑、可复用、可被外部程序驱动的流程。

核心能力

能力说明
积木式流程HTTP / 条件 / 赋值 / 提取 / 延迟 / 日志 / 通知 / 脚本 / 遍历 节点，拖拽连线即成流程
点选生成逻辑运行后点响应里的任意值 → 一键生成提取 / 断言 / 关键字 / 通知 节点
导入浏览器 HAR、cURL 命令、JSON 模板导入，自动生成流程图
调度每个任务独立 cron + 时区 + 抖动；支持手动运行与「调试运行」
日志默认只输出人话日志（qinglong / qiandao 风格），可开调试模式看每步请求与响应
通知12 种渠道：站内通知、Webhook、Bark、Telegram、Server酱、PushPlus、钉钉、企业微信、飞书、Gotify、ntfy、邮件 SMTP
模板调试好的流程存为模板，一份模板派生多份任务，各自填自己的变量
账号安全多用户 + 角色、TOTP 两步验证、会话吊销、凭据静态加密、API Key 作用域与 IP 名单
开放接口REST（OpenAPI 3.1）+ MCP（17 个工具），外部 Agent 可直接操作

设计原则

  • 不分享具体脚本：CheckQ 是平台；具体的签到脚本属于模板市场（后续能力），文档只讲框架能力。
  • 干净日志：默认只有你写的日志节点出现，技术细节按需展开。
  • 凭据不落明文：cookie / token / 密码加密存储，备份默认脱敏。
  • 终端用户优先：面板里不写"给你讲道理"的说明文字，说明走悬停标注或按需出现。
