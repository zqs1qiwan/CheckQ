常见问题

现象处理
找不到入口节点流程成环，所有节点都有入线
HTTP 400不一定是错误，断言通过即可继续；点日志步骤看响应体
超时HTTP 节点超时填秒（30），不是毫秒
变量未定义日志配置开启变量快照，或看运行记录里的「未定义变量」
提示太吵设置 → 通知与推送 → 界面提示 → 仅错误
日志太啰嗦编辑器「更多 → 日志配置」→ 记录范围「仅 log 节点」
忘记密码管理员重置；或按安全说明里的容器命令重置
忘记两步验证码用恢复码；管理员可在「用户管理」重置 2FA
弹窗贴到屏幕左上角 / 打开后背景跟着滚已修复：弹窗用原生 <dialog> 显式居中，遮罩与弹窗用 overscroll-behavior: contain 收敛滚动；不再给页面加锁
弹窗里的下拉菜单点不到已修复：菜单挂到该弹窗内部，避免被模态的 inert 拦住
窄屏顶栏按钮被挤到换行已修复：小屏只留四个等高控件，其余动作收进「更多」
任务失败一次就停了默认会按退避策略自动重试（最多 3 次）；在编辑器「调度 → 失败后重试」可关闭或调次数
怎么知道到底试了几次任务详情显示策略；运行抽屉列出每次尝试与等待；通知结论带「第 N/M 次尝试」
API Key 报权限不足缺哪种能力就补勾哪种作用域（只读 / 可运行 / 可修改）
