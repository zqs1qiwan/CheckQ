交互与视觉规范

本节描述框架的交互契约与视觉令牌，供二次开发与验收对照。所有实现均为浏览器原生能力优先，不含任何业务脚本。

入口契约（定版）

动作结果
点任务名「任务详情」弹窗：任务名 / 备注可改 + 只读概览（调度、时区、状态、重试策略、下次/上次运行、流程规模、变量（敏感项遮蔽）、通知渠道、来源模板、创建/修改时间）
任务行 ···编辑流程 / 复制副本 / 启用或停用调度 / 删除（没有单独的基础信息入口）
编辑器「更多」任务详情 / 通知渠道 / 填入 Cookie / 日志配置 / 存为模板 / 调试运行 等
任务行「日志」或状态徽章连续日志流（同一入口，避免两份视图）

原生 Web 能力

能力做法
弹窗原生 <dialog> + showModal() + closedby="any"；浏览器负责焦点、Esc、背景 inert、顶层渲染与关闭后焦点归还
定位position: fixed; inset: 0; margin: auto; height: fit-content，跨浏览器居中，不依赖 UA 差异
滚动dialog:modal 与 dialog::backdrop 的 overscroll-behavior: contain，不给 <html>/<body> 上锁
菜单Popover API 顶层渲染；位于弹窗内时挂到该 <dialog> 内部，否则会被 inert 拦住
主题<meta name="color-scheme"> + :root 的 color-scheme；日 / 夜 / 自动三段切换
表格语义 <table>/<caption>/<th scope> + sticky 表头 + 容器查询；可聚焦横滚区
表单autocomplete / :user-invalid / aria-label / role="alert"
动效prefers-reduced-motion 降级；长日志 content-visibility: auto
编辑器撤销/重做、复制/粘贴、按层级整理布局、MiniMap、日志↔画布双向定位、单次运行导出 HAR（脱敏）

依据 Modern Web Guidance 1.0；机械扫描 npx modern-web-guidance@latest legacy-scan web/src --json 当前为 0 命中。

控件高度标准 32 / 小 26 / 移动端 38 px同左
  • 冷中性石墨 + 低饱和汽油蓝绿；状态用「小圆点 + 文字」，不用彩色药丸；数字等宽 tabular-nums。
  • 节点配色为低饱和语义色，图标统一线性 SVG（设置用滑块式图标），禁止 emoji 充当图标。
  • 元信息用细竖线分隔的 .meta，不堆中点串。

响应式与对齐

  • 桌面顶栏：品牌 / 新建 / 更多 / 身份文字 / 动作组 / 设置，全部等高、单行、垂直居中。
  • 窄屏（≤640px）：只保留「品牌 / + / ⋯ / 设置」四个 38px 控件，单行不换行；主题、站内通知、文档中心、登录身份收进「更多」。
  • 工具条拆左右两组，组内不拆散、组间才折行；搜索框可伸缩，控件同高。
  • 弹窗 height: fit-content（height: auto 会被 inset:0 拉满再截断，留下大片空白）。
