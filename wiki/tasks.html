任务与流程

节点类型

类型用途
HTTP 请求方法/URL/头/体/断言/超时/后端(fetch·curl)/编码/代理/重试
条件判断jexl 表达式分流
赋值变量或表达式求值
提取正则 / JSON 路径 / 响应头 / Set-Cookie
延迟 / 随机延迟固定或区间等待（避开整点风控）
日志输出人话日志（默认唯一可见的日志）
通知流程内自定义推送
脚本JS 沙箱（vars/last/steps 只读，1s 超时）
遍历数组逐项循环（上限 50 轮）

变量

  • 流程变量在编辑器「流程变量」面板维护；敏感值（cookie/token/密码）落盘加密，API 返回明文以便编辑
  • 模板语法：{{var}}、{{x|urlencode}}、{{x|num}}、{{x|sha256}}、{{now:%Y-%m-%d}}
  • 表达式：=last.json.code == 0（vars.xxx 取变量）

调度

  • cron + 时区 + 抖动（0-N 分钟）；空 cron = 只手动运行
  • 调度弹窗里可随时启用/停用

模板

  • 任务 ··· →「存为模板」；模板携带节点/连线/变量/日志/通知
  • 从模板创建任务时可覆盖变量（如各自的 cookie）
  • 模板导出自动脱敏敏感默认值
